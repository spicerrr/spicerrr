## обо мне

Работаю в **«Агроном-Саде»**, где занимаюсь задачами на стыке бизнес-процессов и данных: описанием предметных сущностей, согласованием справочников и взаимодействием производственных систем.

Развиваюсь в системном анализе цифровых продуктов. Особый интерес — B2C-сервисы, подписочные модели и e-commerce: жизненные циклы сущностей, интеграции, платежные сценарии и согласованность данных.

Сейчас формирую портфолио системного аналитика на основе коммерческого опыта и самостоятельных продуктовых кейсов.

## 🛠 навыки и инструменты

**Системный анализ**
- Сбор, анализ и спецификация требований;
- Use Case, User Story, бизнес-правила, критерии приёмки;
- UML: Use Case, Sequence, State Machine;
- BPMN: моделирование AS-IS / TO-BE;
- ERD: моделирование сущностей и связей.

**Интеграции и данные**
- REST API, JSON, описание запросов и ответов;
- SQL, PostgreSQL, реляционные модели данных;
- Python — обработка данных и автоматизация.
